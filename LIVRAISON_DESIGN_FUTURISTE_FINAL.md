## ✨ EFFETS VISUELS

### Glassmorphism
```css
background: rgba(255, 255, 255, 0.95);
backdrop-filter: blur(20px);
border: 1px solid rgba(0, 212, 255, 0.3);
```

### Néons et Glow
```css
box-shadow: 0 0 30px rgba(0, 212, 255, 0.5);
border-color: rgba(0, 212, 255, 0.5);
```

### Animations
- **pulse-glow**: Logo et icônes (2s infinite)
- **scan**: Ligne de scan sur cards (3s infinite)
- **float**: Icônes flottantes (3s infinite)
- **fadeInUp**: Apparition des éléments (1s)
- **pulse-particles**: Background (8s infinite)

## 🆘 SUPPORT

### Si le design ne s'affiche pas
1. Vider le cache : Ctrl+Shift+R
2. Vérifier le CSS : F12 → Network → futuristic-theme.css
3. Vérifier la console : F12 → Console (pas d'erreurs)
4. Tester autre navigateur

### Si les couleurs sont trop claires/sombres
Modifier les variables dans `futuristic-theme.css`:
```css
:root {
    --bg-primary: #f0f4f8;  /* Ajuster ici */
    --text-primary: #1a202c; /* Ajuster ici */
}
```
